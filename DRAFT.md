Правила разработки:
1. делай анализ кода + идеи до реализации
2. запрещено гадать, если что-то не понимаешь - задавай уточняющие вопросы мне, я буду тебе помогать и отвечать на вопросы и подсказывать
3. предложи простые но надежные решение до написания кода
4. используй принципы минимализма
5. код только для текущей задачи, не придумывай дополнительных идей и заделов на будущее, если этого явно не попросили
6. видишь способ сократить и написать проще - предложи это мне согласовать
7. запрещено делать то, что не просили до обсуждения и согласования 
8. используй принципы KISS, DRY, SOLID, YAGNI 
9. используй переиспользуемые компоненты (модули)
10. разибей задачу на маленькие, понятные части 
11. соблюдай зафиксированный стиль проекта
12. чисти за собой функционал если он больше не используется
13. удаляй зависимости которые больше не нужны из-за изменений
14. верифицируй весь функционал или ручным тестированием или автоматизированными тестами (юнит и другие)
15. для сложных задач используй декомпозицию, опиши план, действие и метод проверки с помощью которого ты будешь верифицировать результат

Идея проекта:
В данном проекте мы разработываем SAAS сервис по созданию кастомизированных книг для детей в формате PDF. Целевая аудитория - родители детей, которые хотят сделать кастомизированные книжки с поучительными историями для своих детей.

Детали проекта:
Модель монетизирования будет подписочная.
Проект - монолит.
Очереди
Монорепо
CI/CD
Domen - pixellabel.com
Suscription and payment - Stripe или Paddle
In settings of the app user can choose his own AI model, but there are also default models available (for text and for illustrations).
Шаблоны - размер, стиль, тема.
Деплой будет через Dockerfile билд и раскатку через deploy 

Стек:
NEST - backend,
NEXT - frontend,
Prisma - ORM,
Redis - cache,
Bool MQ - message queue,
Google authorization

Бизнес сущности:
- пользователи
- шаблоны
- книги
- дети
- иллюстрации
- страницы
- подписки
- рейтинги
- таблица Jobs для фиксации очередей, которые будут использоваться для генерации книжек и иллюстраций

База данных - PostgreSQL
Кеш - Redis
Окружение - Docker
S3 хранилище, совместимое на минио, можно использовать для теста. На продакшене будет любое продавское S3-хранилище.
